Разовый расчёт по паре трендов

Введите адреса двух трендов WebCTRL — аддон прочитает историю за выбранный период, посчитает PI для каждого часа и сведёт их в TWPI.

Адрес — путь по Reference Name (колонка Lookup ID, вид #SITE/Building/Floor/Point); можно вставить постоянную ссылку ABSPATH:1:#…. Не знаете адрес — найдите точку в дереве.

    TWPI — такое постоянное значение Preservation Index, которое за тот же период дало бы тот же ущерб, что и фактически менявшиеся условия. Считается как N / Σ(1/PI): усредняются скорости разрушения, а не сами PI. Точка отсчёта IPI — 20 °C / 45 % RH ≈ 50 лет; для сравнения рядом выводится PI по последнему часу периода.
